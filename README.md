## 맞춤식단 — 식단·알러지 맞춤 외식 안내 사이트

▶ **바로 보기:** https://fhfk-spec.github.io/portfolio/matchum-sikdan/

- **문제:** 비건이나 고단백 식단을 하거나 음식 알러지가 있으면 외식할 곳을 찾기가 어렵다.
- **해결:** 서울·대전에서 조건에 맞는 식당을 골라 두고, 내 식단과 알러지 민감도를 설정하면 맞는 곳만 보여 준다.
- **주요 기능:** 내 식단·알러지 설정, 숨은 재료 경고, 한/영 주문 카드, 숨은 재료 가이드
- **만든 방법:** Claude와 대화하며 기획 → 식당 정보 조사 → 한 장짜리 웹페이지(HTML)로 구현
